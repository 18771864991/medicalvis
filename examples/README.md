# Representative Examples

The examples in `representative_examples.json` were selected to show the
dataset's main variation:

| id | chart | difficulty | query pattern |
| --- | --- | --- | --- |
| MV01677 | Bar | Easy | Prescription count by drug type |
| MV00022 | Line | Hard | Diagnosis-conditioned age distribution |
| MV00048 | Scatter | Medium | Admission-year aggregation |
| MV00021 | Pie | Medium | Prescription route distribution |
| MV01753 | Bar | Extra Hard | Diagnosis and prescription join |
| MV00181 | Line | Extra Hard | Stay length with prescription filter |
| MV00266 | Scatter | Extra Hard | Abnormal lab results by admission year |
| MV04550 | Pie | Extra Hard | Diagnosis and lab join |

The public examples contain NLQ, DVQ, SQL, chart-type, and difficulty metadata.
Eight corresponding HTML renderings are stored in `html/` as limited public
examples. These pages contain the aggregated values required to display those
eight charts; executed values for the full dataset are not redistributed.
